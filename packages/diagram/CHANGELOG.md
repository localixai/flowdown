# @localix-ai/diagram

## 0.1.0

- **First version.** Every kind of Mermaid diagram, read and laid out once, drawn as SVG for a page
  (`toSVG`) and as rows for a terminal (`drawDiagram`, also `@localix-ai/diagram/terminal`). The
  terminal drawing came from `@localix-ai/flowdown/tui/diagram`, which now draws with this package.
