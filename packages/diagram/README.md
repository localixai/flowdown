# @localix-ai/diagram

Mermaid diagrams as agents write them, every kind Mermaid has, drawn as SVG for a page and as boxes and lines for a terminal, from one layout. Any prefix of a stream reads; no dependencies.

```sh
npm install @localix-ai/diagram
```

No dependencies. Part of [flowdown](https://github.com/localixai/flowdown).

## Development

```sh
bun test            # the tests, in a random order
bun run typecheck
bun run size        # each entry against budgets.json
bun run bench       # speed against budgets.json
```
